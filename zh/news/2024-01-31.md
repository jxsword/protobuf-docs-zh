本主题介绍 26.x 系列中 Python 的破坏性变更（breaking change）。

## Python 破坏性变更

### 从 GitHub 中移除对 `setup.py` 和 `setup.cfg` 的支持

在 26.x 发布（release）中，[GitHub 仓库](https://github.com/protocolbuffers/protobuf/tree/main/python)的 `python/` 目录以及 GitHub
[发布 tarball](https://github.com/protocolbuffers/protobuf/releases)
中将不再包含 `setup.py` 和 `setup.cfg`。这意味着将无法再直接从 GitHub 仓库或发布 tarball 构建 Python 包。

发布在
[PyPI](https://pypi.org/project/protobuf/#files)
上的 Python 源码包*仍将*在顶层目录中包含 `setup.py`。对于不想使用我们在 PyPI 上分发的二进制包的用户而言，这是受支持且推荐的 Python 二进制包构建方式。

更多信息请参阅
[#15671](https://github.com/protocolbuffers/protobuf/pull/15671)。
