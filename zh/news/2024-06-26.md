## 停止支持使用 Maven 从源码构建 Protobuf Java

我们计划在 Protobuf Java 4.28 发布（release）中，停止支持使用 Maven 构建系统
从源码构建 Protobuf Java OSS。该能力已在 4.27 发布中被标记为弃用（deprecated）。

在此之后，你仍可继续使用 Bazel 或其他构建系统来构建 Protobuf。
关于从源码构建的更多信息，请阅读
[Protobuf Java README](https://github.com/protocolbuffers/protobuf/tree/main/java)。

此变更可能影响从源码构建 Protobuf 的 Protobuf Java 贡献者。它并不影响大多数
使用仓库中预编译 protobuf-java 或 protobuf-javalite 构件的用户。需要特别说明的
是，我们并不计划停止支持使用 Maven 编译生成代码（gencode），也计划继续在
Maven Central 仓库中提供预构建构件。
