## Go 中的变更 {#go}

### 更新 Go 版本（version）支持政策

Go Protobuf 正在更新其 Go 版本支持政策，改为支持 Go 最近的两个主版本
发布（release），以与官方 [Go 发布政策](https://go.dev/doc/devel/release#policy)
及 [Google Cloud Go 的受支持版本政策](https://cloud.google.com/go/getting-started/supported-go-versions)
保持一致。

此前，为了与当时 Google Cloud Go 的政策保持一致，Go Protobuf 支持 Go 最近的
两个发布版本，并额外多支持一个更早的版本。如今 Google Cloud Go 已将其政策更新为
支持 Go 最近的两个发布版本，Go Protobuf 也相应地调整其支持窗口。

从下一个发布开始，Go Protobuf 的 `go.mod` 文件中的 `go` 语言版本将被设置为
最老的受支持 Go 版本（当前为 **Go 1.26**，即放弃对 Go 1.25 及更低版本的支持）。

此变更也已在 [GitHub 议题](https://github.com/golang/protobuf/issues/1721)中
进行了公告。

### 采用季度发布节奏与版本支持

从 `1.37.x` 发布开始，Go Protobuf 将采用 Protobuf 的季度发布节奏，使其
次要版本编号和发布日程与 `protoc` 保持一致。

我们还在 [Protobuf 版本支持](/support/version-support#go)页面中新增了 Go 章节，
其中记录了 Go Protobuf 当前的支持政策与发布历史。请注意，与其他 Protobuf 语言
不同，Go Protobuf 目前不使用发布分支，且仅支持当前发布；所有发布（包括补丁发布）
都是从 `HEAD` 汇总而来，而非真正的 cherry-pick。我们打算在未来更新这一做法，
以与 Protobuf 的其余部分保持一致。
