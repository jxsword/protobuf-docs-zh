以下公告专门针对 21.x 版本（version），该版本于 2022 年 5 月 25 日发布（release）。按时间顺序呈现的信息请参阅
[新闻](/news)。

## Python 更新 {#python-updates}

我们对 Protobuf 的 Python 语言支持做了一些变更。4.21.0 是继 3.20.1
之后的一个新主版本。新版本基于
[upb 库](https://github.com/protocolbuffers/upb)，与先前的发布版本相比，
其解析性能显著提升，尤其是对大型载荷（payload）。
它还包含适用于 Apple silicon 的预构建二进制模块，
无需手动构建即可获得更高性能。

新的发布版本确实包含一些破坏性变更（breaking change）。具体如下：

*   依赖于隐式创建类的
    [`UnknownFields()`](https://googleapis.dev/python/protobuf/3.17.0/google/protobuf/message.html#google.protobuf.message.Message.UnknownFields)
    方法，已被显式创建的 `UnknownFieldSet` 类所取代。
*   一些非核心特性可能发生了变化，例如某些字符串或错误消息的具体格式。
    这些并不被视为破坏性变更，但仍可能影响你现有的代码库。
*   依赖在 Python 与 C++ 之间共享消息（message）的应用程序在新版本中会失效。
    大多数开发者不会受此影响，但 [Nucleus](https://github.com/google/nucleus)
    以及可能还有其他库的用户会受影响。作为一种变通方法，你可以
    [设置一个环境变量](/reference/python/python-generated#sharing-messages)，
    强制该库保持兼容性。
*   Python upb 要求生成代码（generated code）须由 protoc 3.19.0 或更新版本生成。
