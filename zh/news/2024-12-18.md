## Go Protobuf：全新的 Opaque API

早在 2020 年 3 月，我们就发布了 `google.golang.org/protobuf` 模块，这是 [Go Protobuf API 的一次重大重构](https://go.dev/blog/protobuf-apiv2)。该包引入了一流的[反射（reflection）支持](https://pkg.go.dev/google.golang.org/protobuf/reflect/protoreflect)、一个 [`dynamicpb`](https://pkg.go.dev/google.golang.org/protobuf/types/dynamicpb) 实现，以及便于测试的 [`protocmp`](https://pkg.go.dev/google.golang.org/protobuf/testing/protocmp) 包。

那次发布引入了一个带有新 API 的全新 Protobuf 模块。今天，我们为生成代码（generated code）发布了一个额外的 API，也就是由协议编译器（`protoc`）创建的 `.pb.go` 文件中的 Go 代码。https://go.dev/blog/protobuf-opaque 上的博文解释了我们创建新 API 的动机，并展示了如何在你的项目中使用它。

需要明确的是：我们不会移除任何东西。我们将继续支持现有的生成代码 API，就像我们至今仍在支持较旧的 Protobuf 模块一样（通过对 `google.golang.org/protobuf` 实现进行封装）。Go [致力于向后兼容（backwards compatibility）](https://go.dev/blog/compat)，这一点同样适用于 Go Protobuf！
