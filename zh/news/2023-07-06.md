## 停止支持 PHP 7.x

按照我们的
[PHP 支持政策](https://cloud.google.com/php/getting-started/supported-php-versions)，
我们将停止支持 PHP 7.4 及更低版本。这意味着最低支持的 PHP 版本为 8.0。

如果你正在运行较旧版本的 PHP，可以通过运行 `pecl install protobuf-3.23.3`
安装 Protobuf PHP 扩展的先前发布版本（release）。

## 停止支持 Ruby 2.6

按照我们的
[Ruby 支持政策](https://cloud.google.com/ruby/getting-started/supported-ruby-versions)，
我们将停止支持 Ruby 2.6 及更低版本。这意味着最低支持的 Ruby 版本为 2.7。

## 停止支持 Python 3.7

按照我们的
[Python 支持政策](https://cloud.google.com/python/docs/supported-python-versions)，
我们将停止支持 Python 3.7 及更低版本。这意味着最低支持的 Python 版本为 3.8。
