本节包含在 C++、Java、Python、Go、C\#、Objective-C、Ruby、PHP 和 Dart 中使用 Protobuf 类的参考文档，以及 Protobuf 本身的一些参考文档。每种语言的文档（在可用的情况下）包括：

-   由 Protobuf 编译器根据你的 `.proto` 文件生成的代码的参考指南。
-   为所提供源码生成的 API 文档。

请注意，还有多种语言的 API 正在筹备之中——详情请参阅[其他语言](/reference/other)。
