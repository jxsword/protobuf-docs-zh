<p>如果打开文件时有多条已映射的路径都适用，将按顺序依次搜索。例如，如果你执行了： </p>
<pre>MapPath("bar", "foo/bar");
MapPath("", "baz");</pre>
<p> 然后再执行： </p>
<pre>Open("bar/qux");</pre>
<p> 那么该 <a href='#DiskSourceTree'>DiskSourceTree</a> 会先尝试打开 foo/bar/qux，再尝试 baz/bar/qux，并返回第一个能成功打开的文件。</p>
<p>disk_path 可以是绝对路径，也可以是相对于当前目录的路径，就像你传给 open() 的路径一样。 </p>
</div> <hr><h3 id="DiskSourceTree.DiskFileToVirtualFile.details"><code><a href='#DiskSourceTree.DiskFileToVirtualFileResult'>DiskFileToVirtualFileResult</a> <br>&nbsp;&nbsp;&nbsp;&nbsp;DiskSourceTree::DiskFileToVirtualFile(<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;const std::string &amp; disk_file,<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;std::string * virtual_file,<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;std::string * shadowing_disk_file)</code></h3><div style="margin-left: 16px"><p>给定磁盘上某个文件的路径，查找映射到该文件的虚拟路径。 </p><p>将使用通过 <a href='#DiskSourceTree.MapPath'>MapPath()</a> 创建的第一条 disk_path 包含该文件名的映射。然而，该虚拟路径未必真的可用于打开给定文件。可能的返回值如下：</p>
<ul>
  <li>SUCCESS：映射已找到。*virtual_file 会被填充，使得调用 Open(*virtual_file) 时将打开 disk_file 所指名的那个文件。</li>
  <li>SHADOWED：找到了一条映射，但使用 <a href='#DiskSourceTree.Open'>Open()</a> 打开该虚拟路径最终会返回另一个不同的文件。这是因为另一条优先级更高的映射也匹配此虚拟路径，并将其映射到磁盘上存在的另一个文件。*virtual_file 的填充方式与 SUCCESS 情形相同。*shadowing_disk_file 会被填充为若调用 Open(*virtual_file) 将被打开的那个文件的磁盘路径。</li>
  <li>CANNOT_OPEN：映射已找到且未被遮蔽，但指定的文件无法打开。返回此值时，errno 会指明文件无法打开的原因。*virtual_file 仍会像 SUCCESS 情形那样被设置为虚拟路径，尽管它并无用处。</li>
  <li>NO_MAPPING：表示未找到包含此文件的任何映射。 </li>
</ul>
