</div> <hr><h3 id="TimeUtil.ToString.details"><code>static std::string TimeUtil::ToString(<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;const Timestamp &amp; timestamp)</code></h3><div style="margin-left: 16px"><p>在 Timestamp 与 RFC 3339 日期字符串格式之间进行转换。 </p><p>生成的输出将始终进行 Z 规范化，并按表示精确时间所需使用 3、6 或 9 位小数位。解析（parse）时，任何小数位（也可以没有）以及任何时区偏移都是可接受的，只要它们符合纳秒精度。注意，Timestamp 只能表示从 0001-01-01T00:00:00Z 到 9999-12-31T23:59:59.999999999Z 的时间。把 Timestamp 转换到该范围之外属于未定义行为。参见 <a href='https://www.ietf.org/rfc/rfc3339.txt'>https://www.ietf.org/rfc/rfc3339.txt</a>。</p>

<p>生成的格式示例： </p>

<pre>"1972-01-01T10:00:20.021Z"</pre>

<p>可接受的格式示例： </p>

<pre>"1972-01-01T10:00:20.021-05:00"</pre>
</div> <hr><h3 id="TimeUtil.ToString.details"><code>static std::string TimeUtil::ToString(<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;const Duration &amp; duration)</code></h3><div style="margin-left: 16px"><p>在 Duration 与字符串格式之间进行转换。 </p><p>字符串格式会根据表示精确 Duration 值所需的精度，包含 3、6 或 9 位小数位。例如： </p>
<pre>"1s", "1.010s", "1.000000100s", "-3.100s"</pre>

<p> Duration 可表示的范围是从 -315,576,000,000 到 +315,576,000,000（含两端），以秒为单位。 </p>
</div> <hr><h3 id="TimeUtil.NanosecondsToDuration.details"><code>static Duration TimeUtil::NanosecondsToDuration(<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;int64_t nanos)</code></h3><div style="margin-left: 16px"><p>在 Duration 与整数类型之间进行转换。 </p><p>如果输入值不在 Duration 的有效范围内，则行为未定义。 </p>
</div> <hr><h3 id="TimeUtil.DurationToNanoseconds.details"><code>static int64_t TimeUtil::DurationToNanoseconds(<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;const Duration &amp; duration)</code></h3><div style="margin-left: 16px"><p>结果将向零截断。 </p><p>例如，转换为秒时，“-1.5s” 会截断为 “-1s”，“1.5s” 会截断为 “1s”。如果输入的 duration 无效，或结果超出 int64 的范围，则属于未定义行为。如果 duration 不在 Duration 的有效范围内，或其 nanos 值无效（即大于 999999999、小于 -999999999，或与秒部分的符号不同），则该 duration 无效。 </p>
</div> <hr><h3 id="TimeUtil.NanosecondsToTimestamp.details"><code>static Timestamp TimeUtil::NanosecondsToTimestamp(<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;int64_t nanos)</code></h3><div style="margin-left: 16px"><p>从整数类型创建 Timestamp。 </p><p>整数值表示自纪元（Epoch）时间起经过的时间。如果输入值不在 Timestamp 的有效范围内，则行为未定义。 </p>
</div> <hr><h3 id="TimeUtil.TimestampToNanoseconds.details"><code>static int64_t TimeUtil::TimestampToNanoseconds(<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;const Timestamp &amp; timestamp)</code></h3><div style="margin-left: 16px"><p>结果将向下截取到最接近的整数值。 </p><p>例如，对于 “1969-12-31T23:59:59.9Z”，TimestampToMilliseconds() 返回 -100，TimestampToSeconds() 返回 -1。如果输入的 Timestamp 无效（即其秒部分或 nanos 部分不在有效范围内），或返回值无法容纳于 int64，则属于未定义行为。 </p>
</div> <hr><h3 id="TimeUtil.TimeTToTimestamp.details"><code>static Timestamp TimeUtil::TimeTToTimestamp(<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;time_t value)</code></h3><div style="margin-left: 16px"><p>与其他时间/日期类型之间的转换。 </p><p>注意，这些类型的精度与时间范围可能与 Timestamp/Duration 不同。转换为精度较低的类型时，该值将被截取为可表示的最接近值。如果该值超出结果类型的范围，则返回值未定义。</p>
