</ul>
<p>后置条件：</p>
<ul>
  <li>上次调用 <a href='#GzipInputStream.Next'>Next()</a> 所返回的最后一个缓冲区的最后 "count" 个字节会被退回流中。随后对 <a href='#GzipInputStream.Next'>Next()</a> 的调用会先再次返回相同的数据，然后才产生新数据。 </li>
</ul>

<p>前置条件：</p>
<ul>
  <li>"size" 和 "data" 不得为 NULL。</li>
</ul>
<p>后置条件：</p>
<ul>

  <li>否则，"size" 指向缓冲区中的实际字节数，"data" 指向该缓冲区。</li>
  <li>此缓冲区的所有权仍属于流；缓冲区只在该流的其他某个方法被调用或流被销毁之前保持有效。</li>
  <li>调用者存入此缓冲区的任何数据最终都会被写到输出（除非调用了 <a href='#GzipOutputStream.BackUp'>BackUp()</a>）。</li>

<p>前置条件：</p>

  <li>count 必须小于或等于上次调用 <a href='#GzipOutputStream.Next'>Next()</a> 所返回的最后一个缓冲区的大小。</li>
  <li>调用者必须尚未向该缓冲区的最后 "count" 个字节写入任何内容。</li>
</ul>
<p>后置条件：</p>
<ul>
  <li>上次调用 <a href='#GzipOutputStream.Next'>Next()</a> 所返回的最后一个缓冲区的最后 "count" 个字节将被忽略。 </li>
</ul>
