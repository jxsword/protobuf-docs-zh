</ul>
<p>后置条件：</p>
<ul>

  <li>否则，"size" 指向实际读取的字节数，"data" 指向一个指针，该指针指向包含这些字节的缓冲区。</li>

</ul>

<p>前置条件：</p>
<ul>
  <li>最后调用的方法必须是 <a href='#FileInputStream.Next'>Next()</a>。</li>
  <li>count 必须不超过上次调用 <a href='#FileInputStream.Next'>Next()</a>。</li>
</ul>
<p>后置条件：</p>
<ul>
  <li>上次调用 <a href='#FileInputStream.Next'>Next()</a> 所返回的最后一个缓冲区的最后 "count" 个字节会被退回流中。随后对 <a href='#FileInputStream.Next'>Next()</a> 的调用会先再次返回相同的数据，然后才产生新数据。 </li>
</ul>
