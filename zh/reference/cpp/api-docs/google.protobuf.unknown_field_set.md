<p>要获取附加到任一消息（message）上的 <a href='#UnknownFieldSet'>UnknownFieldSet</a>，请调用反射（Reflection）接口的 <a href='google.protobuf.message#Reflection.GetUnknownFields'>Reflection::GetUnknownFields()</a>。</p>

<p>该类必然与 Protobuf 线路格式（wire format）绑定，这与独立于任何序列化（serialization）方案的 <a href='google.protobuf.message#Reflection'>Reflection</a> 接口不同。 </p>
