<p>事实证明，DynamicMessage 要想正常工作，就需要为其类型构造一些额外的信息。这些信息中的大部分可以在同一类型的所有 DynamicMessage 之间共享。但是，把这类信息缓存在某种全局映射中可不是个好主意，因为针对某个特定描述符（descriptor）缓存下来的信息可能会比该描述符本身存活得更久。为了避免这个问题，<a href='#DynamicMessageFactory'>DynamicMessageFactory</a> 封装了这个“缓存”。由同一个工厂创建的同一类型的所有 DynamicMessage 都会共享同一份支持数据。与特定工厂一起使用的任何描述符都必须比该工厂存活得更久。 </p>
